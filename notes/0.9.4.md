## 无限工坊 0.9.4

无限工坊：用 AI 写魔兽插件。这一版加了英文界面和游戏里的调试窗口，API 手册标出每个函数插件能不能调用。

- 英文界面：设置里选「自动（跟随系统）」「简体中文」或「English」，切换立即生效。程序的提示、自检、托盘菜单都有英文；新建插件生成的代码注释和 AGENTS.md 也跟着用英文。
- API 手册标出能否调用：每个条目注明插件可以调用、有限制还是受保护，并写出依据。可以按这三类筛选，不输关键词也能列出来。对象方法写成 `Frame:Hide` 的形式，不再误标为受保护。
- 不搜索也能翻手册：按命名空间、全局函数、对象方法浏览，每组带一条可调用比例。手册资料更新到客户端 1.60.1.70245，新版本新增、改动的条目带标记。
- 在手册里直接试：函数直接在游戏里调用，返回值按文档展开；枚举读出来和手册对照；事件在游戏里监听。受保护的函数不提供运行。
- 概览重新排版：上面一条状态带（连接状态、说明、可做的操作、链路读数），下面是游戏和开发组件两张卡，以及最近动态。
- 游戏里的调试窗口：用 /wb log、小地图按钮右键、按键设置里的快捷键，或面板概览的「调试输出」打开。报错（带调用栈，同一个报错合并计数）、警告、被拦截的操作、print 输出、Agent 运行的代码（成败、耗时、返回值）都实时列出，分「全部」「报错」「运行」「输出」四页。窗口关着时，新报错的数目显示在小地图按钮上。
- 热加载提示条：Agent 热加载插件后，屏幕上方提示「已热加载 插件名 · N 个文件 · 耗时」。出错或 Agent 的代码运行失败时变红，点一下打开调试窗口。不想要可以在面板「设置」里关掉，关掉后照旧在聊天框里说。
- 修复：安装程序和便携包里的程序名显示成乱码（0.9.0–0.9.3 都有）。
- 修复：程序还在启动时又打开一次（或有命令连它），可能多开一个窗口，或多出一个看不见的后台实例一直挂着。
- 这次更新后开发组件会更新到 0.9.4（游戏关着时自动装好），装好后完整重启游戏。
