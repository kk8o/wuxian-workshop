## 无限工坊 0.9.13（草稿）

无限工坊：用 AI 写魔兽插件。这一版加了扩展：说出一个想法，Agent 先查证能不能做，再在运行中的游戏里做成原型。扩展可以在游戏里运行，也可以是这台电脑上的一个进程，或者两边各一半。

- 扩展：用来验证想法的原型。
  - 一个对话做完：Agent 只连无限工坊的 MCP，先读 `guide`，按「探一下 → 游戏内 → 本机 → 游戏 · 本机」四档从最便宜的一档做起，最后给出结论（能做 / 有条件能做 / 不能做）和证据。`guide` 带六个走完全程的案例。
  - 三种扩展同一套工具：`new_extension` 新建（`where`：`game`、`local`、`both`），改完 `extension_load`（检查、装进游戏或重启进程、跑测试），只有你能做的事（批准、重启游戏）用 `extension_wait` 等，出错看 `extension_logs`。
  - 本机扩展：游戏里做不到的事（声音、读写文件、联网、本地模型、要跑很久的活）写成这台电脑上的一个进程。它的能力、选项和游戏里的扩展是同一套，Agent 用到的同样是 `wk_` 工具。第一次用到时才启动；清单写 `"start": "workshop"` 的随工坊启动，适合要先加载模型的。停止时结束整个进程树。
  - 扩展文件夹与扩展包：一个文件夹、一份清单 `wuxian-extension.json`，可以带游戏插件（`addons/`）。「打包分享」（`extension_pack`）生成一个 zip，对方在 App 里导入。
  - 批准：导入的扩展包、新登记的本机扩展，运行前要你在 App 里批准。批准前先看摘要：往游戏里装什么、在这台电脑上运行什么、Agent 会读到什么；同编号替换时列出和现有那份的差别。可以让 Agent 先审阅（`guide` 的 `review` 一章），批准只能由你点。设置里的「本机扩展批准」可以改成自动，供开发时使用；扩展包始终询问。
  - 应用：扩展可以带「应用」，也就是交给 AI 的一段会话（听什么、看什么、能不能发言、节奏）。`wuxian listen <应用>` 或 Python SDK 接上去；本机扩展可以给已有的应用补资料（唤醒备注、技能补充），不用改那个应用。
  - 反射：听到游戏里或本机扩展的某条消息就直接调一个能力（比如进战斗遇到精英就播一句台词），不用叫醒 AI；`reaction_set` 设置，最多 32 条。
- App：
  - 「扩展」页重排为「扩展框架、内置、已添加、扩展目录」，每行标明在哪运行（游戏、本机、游戏 · 本机）。详情里有开关、按声明生成的设置、载入、停止、检查结果、日志、打包分享和移除。
  - 新建扩展的对话框直接写想法，生成一句交给 Agent 的话；手动填表在第二个页签。
  - 「接入 Agent」页新增「无限图鉴」（一键接入图鉴的 MCP，查游戏事实）和「应用」（正在运行和可以开始的应用，一键复制交给 AI 的启动语）。
  - 游戏插件装不上时会说明原因（文件夹被别的插件占用、版本不够等），不再只显示失败。
- 很长的结果整段连发：AI 从游戏里取很长的回答（比如整个拍卖行的扫描、层次很深的界面检查）时，开发组件把第一块之后的内容按 32 KB 一段连续发出，不再一块约 3.9 KB 地一问一答。实测 3.5 MB 用 241 秒，比原来快约 1.6 倍。
  - 命令行新增 `wuxian run --whole`：把代码的第一个返回值完整拿回（最多 16 MB），不再在 4000 字节处截断。
  - 连发时，其他 `run` 的结果照样先回来；窗口最小化或在加载画面时会暂停，连接恢复后从断开的地方接着发，丢了的段会单独补要。
  - 需要开发组件 0.9.13；游戏里还是旧版本时，自动改为一次同时要 8 块。
- 命令行：`wuxian ext list | add | summary | remove | load | stop | wait | set | check | new | pack | install | dir | logs`、`wuxian wk <能力> [参数]`、`wuxian reaction list | set | clear`、`wuxian listen <应用>`；`wuxian events` 新增 `--once`、`--max`。
- Python SDK 0.8.0：`Client`（游戏外的程序听应用、调能力）、`Extension`（写本机扩展）和测试用的 `ExtensionTest`。工坊启动扩展时自动放进 PYTHONPATH，不用复制。
- 扩展框架 WuxianKit 更新到 0.6.0：框架本身不带应用；游戏里 `/wk` 窗口和 App 的「扩展」页是同一套分组，本机扩展也列在里面。
- 这次更新后，开发组件会更新到 0.9.13（游戏关着时自动装好）。
