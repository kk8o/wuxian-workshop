## 无限工坊 0.9.10

无限工坊：用 AI 写魔兽插件。这一版让 App 打开更快、在后台几乎不占资源，「扩展」页重新整理成列表加详情。

- 打开更快：窗口约 1.2 秒出现（原来约 2.4 秒），页面约 2 秒可用（原来约 3.6 秒）。
  - 先出窗口，服务在后台同时启动；MCP 服务改在启动之后加载，Agent 在那之前连上来时稍等一下。
  - 首次读取状态不再解析整个 API 手册内容包；页面文件不再查询 Windows 注册表；去掉了每个请求都要经过的一道额外处理。
- 后台更省：
  - 窗口关到托盘后页面不再绘制。原来在高刷新率屏幕上，托盘里的 App 仍会占用一个多 CPU 核心。
  - 概览页的 ∞ 流光和加载动画改为每秒 20 帧，只在看得见时运行；系统开启「减少动态效果」时不动。
  - 寻找游戏窗口的开销降到原来的约 1/20：每秒最多完整搜索一次，其余时间只复查已找到的窗口。
- 「扩展」页改版，和「插件」页一样左边列表、右边详情：
  - 列表：扩展框架（版本与状态）、系统扩展、自定义扩展，底部是 Agent 会话。
  - 自定义扩展的安装包和游戏里运行的扩展合成一项；安装、更新、卸载放在详情标题右边。
  - 详情分「概况」「Agent 工具」「更新内容」：状态、版本、需要的插件和工具数集中显示，需要玩家确认的工具标黄。
- 修复：
  - 快速连开两次不再出现两个窗口。
  - 服务启动失败时显示错误页。
  - MCP 服务加载失败时不再对外给出 /mcp 地址。
- 这次更新后，开发组件会更新到 0.9.10（游戏关着时自动装好）。
