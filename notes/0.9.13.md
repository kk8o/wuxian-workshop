## 无限工坊 0.9.13（草稿）

- 很长的结果整段连发：AI 从游戏里取很长的回答（比如整个拍卖行的扫描、层次很深的界面检查）时，开发组件把第一块之后的内容按 32 KB 一段连续发出，不再一块约 3.9 KB 地一问一答。以一份 2.3 MB 的拍卖行扫描估算，要画的帧少约三成，向游戏发的请求从约 590 次减到 1 次。
  - 命令行新增 `wuxian run --whole`：把代码的第一个返回值完整拿回（最多 16 MB），不再在 4000 字节处截断。
  - 连发时，其他 `run` 的结果照样先回来；窗口最小化或在加载画面时会暂停，连接恢复后从断开的地方接着发，丢了的段会单独补要。
  - 需要开发组件 0.9.13；游戏里还是旧版本时，自动改为一次同时要 8 块。
- 程序加载器：插件在游戏里跑，程序在游戏外跑。AI 可以用 `new_program` 新建一个程序（清单 `wuxian-program.json`、用 Python SDK 的 main.py、一份 SDK），`program_start` 启动、`program_logs` 看输出和退出码、改完 `program_start` 带 restart 重启，`program_stop` 停止。
  - 程序崩了不会自动重启，输出和退出码留着看；停止时结束整个进程树。
  - 程序可以驱动一个 WuxianKit 应用：登记后，游戏里应用卡片上的「开始」就能启动它；停止时先停应用，程序自己退出。
  - 守护进程重启后会认回还在跑的程序；工坊退出时停掉它管的程序。
  - 命令行 `wuxian program list | add | remove | start [--restart] | stop | logs [-f]`；Python SDK 0.6.1 新增 `program_app()`，`Client().app(*program_app())` 就按清单打开应用。
