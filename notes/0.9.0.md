## 无限工坊 0.9.0

第一个公开版本：给有一点编程基础、配合 AI Agent（Claude Code、Codex、Cursor）做《魔兽世界》「无限」插件的人。

- 连着正在运行的游戏：Agent 通过 MCP 把 Lua 热加载进游戏、读报错和 print 输出、截图，不用重启游戏。
- 新建插件：选个模板一键生成，自带热加载约定和给 Agent 的说明（AGENTS.md）。
- API 手册：这个客户端自己的 API 文档（6596 个函数、1805 个事件）和使用规矩，Agent 直接查；网站上有新版会自动更新。
- 开发台：日志、运行 Lua、截图、请求重载、保存即热加载。
- 游戏里的开发组件（/wb 设置面板、小地图按钮、对话框）和 App、网站同一套深色金色样式。
- 自检与修复：缺 WebView2 运行时、.NET Framework 时提示，一键下载微软官方安装程序。
- 自动更新：有新版本时提示，下载后重启即可。
