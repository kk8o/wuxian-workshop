## 无限工坊 0.9.9

无限工坊：用 AI 写魔兽插件。这一版让游戏和 App 之间的通道更快、更不容易卡住，游戏里的开发组件换了新面板，`check` 能查出更多真会在游戏里报错的写法。

- 更快：
  - 送进游戏的大段代码和数据先压缩再发，游戏里解开、校验后才执行。
  - 游戏回给 App 的长消息先压缩再上屏：读扩展框架的完整说明从约 7.5 秒降到约 6 秒，检查整个界面两层（约 160 KB）从 42 秒降到 18 秒。
  - 每帧 0.15 秒、按时换帧（原来大多停 0.2 秒）；链路不稳时自动退回 0.2 秒。
- 更稳：
  - 修复 0.9.8 的一个卡死：重载界面后大批消息同时要上屏时，帧码可能一直闪、同一批消息反复重发。现在重发不再挤在新消息前面、间隔逐次加长，久问无果的一条会被放弃。
  - 长回答（inspect、addon_api、trace 等）中途遇到窗口最小化、载入画面或断线，丢掉的部分等链路恢复后单独补取，不再整个失败。
  - App 在长消息传到一半时重启，会把它补全。
  - 待发消息积压时，可以在面板「诊断」页点「清空待发」，或输入 `/wb flush`。
  - 重载界面后，各个 Agent 会话不再各自向游戏要一遍扩展框架的说明，守护进程问一次、大家共用。
- 帧码新样式：数据格沿 ∞ 排开，空闲时是一个小 ∞；长消息分段发送，每段装七到九成，∞ 随之起伏。
- 开发组件改版：
  - 面板重排：「概览」是连接状态、需要处理的提示、本次会话的四个数字和调试输出的最近几行（点一行打开调试窗口）；「设置」分帧码、Agent、界面三组；「诊断」列出链路的各项数字，加上「清空待发」「复制诊断信息」。
  - 小地图按钮下方有状态标记，提示框改为两列。
  - 聊天里的提示精简：登录不再刷屏，只在连上、断开、重连时各说一句。
  - Agent 请求重载界面时写明原因，显示在重载按钮上方；点「稍后」后，App 不再一直显示「等待点击」。
  - 调试输出里，Agent 调用插件公开的函数写明调用了谁；没运行的代码（热加载已关闭等）也留一行记录。
- `check` 新增两类问题：少传了必填参数；把机密值（如 `UnitHealth` 的结果）拿去运算、比较、取长度、当表的键等客户端会拒绝的用法。先用 `issecretvalue` 或插件自己的判断函数（包括 `E:IsSecretValue(x)` 这类写法）判断过的不报；只在战斗等受限状态下才是机密值的，汇总成一条提示。拼错的 API 名字在条件分支里只算警告，但也给出正确写法。
- API 手册以游戏实测为准：补上文档没写、游戏里实际有的函数与常量表（`Undocumented`），标出文档里有、这个客户端没有的函数（`NotInClient`）；`check` 不再误报这些名字。内容包更新到客户端 1.60.1.70338。
- 「扩展」页改版：扩展包卡片；已加载的扩展分「系统扩展」「自定义扩展」两组；其他插件提供的扩展（如 EllesmereUI 的扩展）显示在它所扩展的扩展包下面，缺少需要的插件时不给安装。
- 这次更新后，开发组件会更新到 0.9.9（游戏关着时自动装好）。这一版的开发组件有新文件，装好后要完整重启游戏，只重载界面不够。
