## 无限工坊 0.9.13（草稿）

- 很长的结果整段连发：AI 从游戏里取很长的回答（比如整个拍卖行的扫描、层次很深的界面检查）时，开发组件把第一块之后的内容按 32 KB 一段连续发出，不再一块约 3.9 KB 地一问一答。以一份 2.3 MB 的拍卖行扫描估算，要画的帧少约三成，向游戏发的请求从约 590 次减到 1 次。
  - 命令行新增 `wuxian run --whole`：把代码的第一个返回值完整拿回（最多 16 MB），不再在 4000 字节处截断。
  - 连发时，其他 `run` 的结果照样先回来；窗口最小化或在加载画面时会暂停，连接恢复后从断开的地方接着发，丢了的段会单独补要。
  - 需要开发组件 0.9.13；游戏里还是旧版本时，自动改为一次同时要 8 块。
- 本机扩展：游戏里做不到的事（声音、读写文件、联网、本地模型、要跑很久的活）可以写成这台电脑上的一个进程。它的能力、来源、选项和游戏里的 WuxianKit 扩展是同一套，AI 用到的同样是 `wk_` 工具，不进游戏也能用。AI 先读 `extension_guide`，用 `new_extension` 新建（清单 `wuxian-extension.json`、用 Python SDK 的 main.py、AGENT.md 和测试），改完 `extension_load`（检查、重启、跑测试），出错看 `extension_logs`。
  - 第一次用到它的能力时才启动；清单写 `"start": "workshop"` 的随工坊启动，适合要先加载模型的。崩了下次调用再起；停止时结束整个进程树，工坊退出时一起停掉。
  - App「扩展」页新增「本机扩展」一栏：开关、按扩展的声明生成的设置、载入、停止、检查结果和日志。
  - 反射：听到游戏里或本机扩展的某条消息就直接调一个能力（比如进战斗遇到精英就播一句台词），不用叫醒 AI；`reaction_set` 设置，最多 32 条。
  - 本机扩展带的应用会登记到 WuxianKit，可以「交给 AI」。
  - 命令行 `wuxian ext list | add | remove | load | stop | set | check | new | logs`、`wuxian wk <能力> [参数]`、`wuxian reaction list | set | clear`；Python SDK 0.7.0 新增 `Extension` 和测试用的 `ExtensionTest`，工坊启动扩展时自动放进 PYTHONPATH，不用复制。
