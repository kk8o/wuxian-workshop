## 无限工坊 0.9.1

把 Agent 接上、让它开始写插件，现在几分钟就能走完。

- 新的「开始」页：五步带你走完——找到游戏、装开发组件、进入游戏、接上 Agent、建第一个插件，每一步做完自动打勾（第一次打开时自动出现，以后在左边的「开始」里）。
- Agent 一键接入：Claude Code、Codex、Cursor 点一下就登记好（用户级设置，所有项目都能用），还能检查 Agent 能不能真的启动无限工坊；其他支持 MCP 的 Agent 给出通用配置。
- 「接入 Agent」页换成一键接入卡片；命令行新增 `wuxian agents`。
- 找不到游戏时，可以直接选择游戏文件夹。
- 自检里插件的版本改为和程序自带的那份比较：只更新程序时，不再提示重装插件。
