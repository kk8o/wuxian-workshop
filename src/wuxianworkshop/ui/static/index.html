开始使用

用 AI 写魔兽插件

无限工坊让你的 AI Agent（Claude Code、Codex、Cursor、Trae、WorkBuddy 等）自己写插件、自己调试：从零写一个新插件，或修改你已经装着的插件（别人写的也行）；写完先检查，再在正在运行的游戏里试，看报错、print 输出和截图，在游戏里执行 Lua 查状态，对照这个客户端自己的 API 手册找到原因、改好再试。你只需说清想要什么，在游戏里验收。

下面五步走一遍大约 5 分钟；做完的步骤会自动打勾，随时可以回到这一页（左边的「开始」）。

  1. 找到游戏

    正在检查…

  2. 装开发组件

    开发组件是两个普通插件（无限工坊、WoWBridge）。装进游戏的 AddOns 之后，无限工坊才能和游戏说话。

    先找到游戏目录。

  3. 进入游戏

    启动游戏，选角色进入游戏世界（装完开发组件后要完整退出游戏再启动，/reload 不够）。连上后这里自动打勾。

  4. 接上 Agent

    把无限工坊登记给你的 Agent（用户级设置，所有项目都能用），它就能自己写插件，在游戏里试、看报错和截图来调试。

    正在查找 Agent…

  5. 第一个插件

    建一个最小的插件，热加载进游戏，看它在游戏里说话。
